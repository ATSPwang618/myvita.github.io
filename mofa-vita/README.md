# 魔法使之夜 · PS Vita 宣传站

为 [mofa-vita](https://github.com/ATSPwang618/mofa-vita) 制作的非官方移植宣传页面。以施法原画、景深光效与标题菜单呈现作品，配合实机画廊、开发历程与安装入口。

## 本地预览

这是纯静态网站，无需安装 Node.js 依赖或构建框架。在仓库目录运行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

浏览器访问 **http://127.0.0.1:4173/**。修改文件后刷新页面即可。

## 页面内容

- 三张手动切换的首页原画，默认展示青子施法原画。
- 原生 GXM、960×540 演出与开源移植介绍。
- 用户提供的 PS Vita 机身素材内嵌实机画面，以及四张可放大查看的实机截图。
- 2023 年 6 月至 2026 年 11 月的开发时间轴，收录五张历史视频记录。
- 安装步骤、资源目录复制、项目文档入口和常见问题。
- 桌面与手机布局、移动导航、键盘操作和减少动态效果偏好支持。

## 文件与维护

| 文件 | 用途 |
| --- | --- |
| `index.html` | 中文文案、页面结构、截图列表、项目链接和分享元数据 |
| `styles.css` | 色彩、版式、动效与响应式规则 |
| `app.js` | 原画切换、导航、截图弹窗和路径复制 |
| `assets/` | 网页专用图片和图标 |
| `assets/provenance.json` | 图片来源相对路径、原文件 SHA-256、尺寸和体积 |
| `doc/verification.md` | 本次本地检查记录与发布前注意事项 |
| `.nojekyll` | 静态文件直接发布标记 |

原画来自可编辑 PNG 工程，四张实机画面来自游戏源码仓库的 `doc/screenshots/`。网站使用独立的 WebP 副本，原有八张图片合计约 **715 KiB**；转换不会修改游戏运行资源或 PNG 工程。图片延迟加载，首页仅优先加载第一张原画，不自动播放视频或声音。

更换图片时，更新对应文件与 HTML 的尺寸、替代文字，并补充来源记录。安装链接目前指向游戏仓库的 `perf/render` 文档；若文档迁移分支，请同步更新。页面没有虚构下载地址或全程帧率承诺，实机截图中的性能数字属于拍摄时的历史状态。

预期公开地址：**https://atspwang618.github.io/myvita.github.io/mofa-vita/**。

从仓库根目录运行本地 HTTP 服务后，访问 `/mofa-vita/`。原画素材及游戏源码不需要随站点部署；仅上传本目录中的网页文件。
