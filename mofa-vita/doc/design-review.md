# Frontend Design 审查与改版

2026-11-09。本轮为本地设计候选，未发布。后续用户明确要求现代炫酷、动感十足，以下第一轮克制方案已被动态版本替代。

## 旧版问题

1. 大写英文眉题、数字编号、细线和箭头在几乎每个区块重复，形成模板感。
2. 首页大口号占据首屏，实际作品入口过低；项目页人物渐变大图加双按钮，缺少魔夜独有的空间气氛。
3. 三栏卖点卡片、参数条、装饰光点和逐块渐入过多，技术规格抢了游戏内容的注意力。
4. “掌心”“热爱”“故事继续”反复出现，开发者真实投入和历史证据反而成了次要信息。
5. 设计读起来像一个宣传模板换了图片，作品导航与游戏子站的角色也不够清晰。

## 本轮设计约定

- 色彩：夜空 `#10182a`、深墨 `#080d17`、月白 `#e7e8ee`、灰紫 `#a8aec0`、灯火 `#d5b687`。暖色只用于入口与交互焦点。
- 字体：宋体系列用于中文作品标题和短标题，系统无衬线用于说明；英文仅保留作品名称，取消装饰性口号。
- 总站：个人作品陈列。简介放在左侧，现有作品在右侧首屏直接出现；延续维护者的“VITA的故事，依然未完。”标题。
- 子站：视觉小说标题画面。洋馆夜景完整铺开，作品名与菜单放在下方，材质切换是用户主动操作。
- 下文：实机展示与具体适配说明、四张截图、完整开发记录、安装步骤。取消重复营销结尾。
- 动效：保留原画主动切换与弹窗反馈，去掉随机星点、逐块渐入和悬浮装饰。

布局草图：

```text
总站                         魔夜子站
署名 / 外部链接              简洁项目导航
简介       作品封面           洋馆夜景
           标题 + 展览入口    作品名 / 标题菜单
其他作品预留                 实机图 + 具体适配说明
                             截图 / 开发记录 / 安装
```

取舍：不引入新的卡片套件、装饰徽章、假播放按钮或全屏粒子。保留机身图片、全部历史截图、现有链接与可访问交互，不以样式改版改变项目事实。

## 本轮验证

桌面 1280×720 与手机 390×844 检查了标题画面、机身展示及时间轴；总站和子站在 320 像素宽度均无横向溢出。原画切换、截图弹窗、Escape 关闭、路径复制和移动导航收起已验证。64 个本地资源/锚点引用检查通过，JavaScript 语法与 diff 空白检查通过，浏览器无错误或警告。

本地预览：`http://127.0.0.1:4175/` 与 `/mofa-vita/`。旧版源文件备份于仓库忽略目录 `.work/before-design-review/`。本次保留维护者已有的 README 名称和总站标题修改，未提交、未推送，线上仍为此前部署版本。


## 用户反馈后的动态版本（当前候选）

第一轮过于简洁，未满足用户要的动感。本轮保留具体文案和历史证据，改用施法原画作为首屏，加入景深、缓慢镜头推进、光束、粒子、扫光按钮与可暂停的动效。总站作品封面改为深色透光展板、悬停倾斜和浮动掌机。

- 默认开启动态效果；系统减少动态效果时默认暂停，并提供固定的暂停/开启按钮。
- Canvas 限定 24/46 个粒子与最高 1.5 倍像素密度，离屏和后台停止循环。
- 精细指针设备启用倾斜与视差；手机保留场景、粒子与滚动进入，不强加鼠标交互。
- 不接管滚动、不自动播放声音、不阻塞导航，不自动轮播原画。
- 魔夜的动效脚本仍留在 `mofa-vita/motion.js`；总站使用自己的 `hub.js`，部署脚本同步收录。

本地预览端口仍为 4175，未推送或改变线上版本。

动态候选验证：两站动效暂停/恢复、原画切换与标签对应、手机导航、320 像素无溢出检查通过；浏览器无错误/警告。静态部署构建通过，66 个本地引用/锚点检查通过，部署产物包含 `hub.js` 与 `mofa-vita/motion.js`。实机截图、五张开发历史图与安装链接保留。鼠标倾斜已实现，未将静态截图当作其逐帧性能验收。
