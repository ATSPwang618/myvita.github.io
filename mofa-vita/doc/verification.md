# 本地验证记录

日期：2026-11-09。

## 实现范围

纯 HTML / CSS / JavaScript 静态页面，无构建依赖、第三方字体、远程图片或统计脚本。八张网页图像共 731,702 字节；游戏运行包与可编辑工程保持原样。

## 浏览器检查

使用 Codex 内置浏览器，在本地 HTTP 服务中检查：

- 桌面默认 1280×720：首屏排版、项目介绍、机身示意与截图画廊。
- 手机 390×844：首页、移动菜单、单列画廊和安装说明。
- 320×740 窄屏及 768×1024 平板：检查横向溢出与首屏控件间距，均无横向溢出。
- 三张首页原画切换，当前选中状态与标题同步。
- 四张实机截图弹窗，前后切换、方向键、Escape、关闭后焦点恢复。
- 资源目录复制成功反馈，常见问题展开。
- 本地页面未见浏览器控制台错误或警告。

测试过程中修正了短桌面视口的首屏底部重叠，并为弹窗添加显式 Escape 处理；移动端 GitHub 图标补充了可访问名称。

另修正了 320 像素视口的参数栏溢出。JavaScript 语法检查与 `git diff --check` 通过；静态检查覆盖 55 个资源/链接引用和 25 个唯一 ID，本地文件、页内锚点、图片清单体积均匹配。通过 GitHub 只读接口确认远端 `perf/render` 存在资源提取与安装文档。以上均不代表已部署线上站点。

## 发布状态与边界

本次没有执行远端推送、Pages 配置或部署，因此不能把本地检查称为线上验收。当前预览依赖本机 HTTP 服务；重启服务的命令见仓库 README。

动效提供 `prefers-reduced-motion` 样式与脚本分支。此次未在实体手机或 Safari 上运行测试，不将 Chromium 检查外推为所有浏览器均已实测。
